// Dataset & Setup

dvdrental

Semua contoh menggunakan dvdrental — database rental film PostgreSQL yang realistis dengan 15+ tabel dan data transaksi nyata.

# Clone repo
git clone https://github.com/thosangs/dibimbing_sql.git
cd dibimbing_sql

# Jalankan PostgreSQL + dvdrental via Docker
docker compose up -d

# Koneksi
psql "$POSTGRES_URL"

# Jalankan contoh per day
psql "$POSTGRES_URL" -f day_13/examples/ddl.sql
